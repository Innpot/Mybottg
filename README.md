# BarberBeard Telegram Bot

BarberBeard — это Telegram-бот для автоматизации записи клиентов в барбершоп. Бот позволяет пользователям выбрать услугу, мастера, дату и время посещения, а также оставить контактные данные для подтверждения записи.

## Основные возможности

* Запись на услуги барбершопа через Telegram.
* Выбор мастера из списка доступных специалистов.
* Выбор удобной даты и времени посещения.
* Проверка занятости временных слотов.
* Хранение информации о клиентах и записях в базе данных SQLite.
* Удобный интерфейс с использованием кнопок Telegram.
* Предотвращение создания дублирующихся записей.

## Используемые технологии

* Python 3
* aiogram
* SQLite
* Telegram Bot API

## Цель проекта

Проект разработан для автоматизации процесса записи клиентов в барбершоп и снижения нагрузки на администраторов. Использование Telegram-бота позволяет клиентам самостоятельно выбирать удобное время посещения и получать быстрый доступ к услугам барбершопа.
